# Weather Style Lab ☂

날씨·체형·퍼스널 컬러에 맞춰 오늘의 코디를 추천하는 안드로이드 앱입니다.

## 주요 기능
- **실제 날씨 연동**: Open-Meteo 예보(기온·체감온도·강수확률·바람)와 미세먼지, 현재 위치 지원
- **맞춤 추천**: 외출 목적(일상·출근·면접·데이트·운동), 선호 핏, 퍼스널 컬러, 체형을 점수로 반영해 상위 3개 코디 추천
- **추천 이유 표시**: 예) "체감 9℃이고 비가 예상돼서 바람막이와 방수 신발을 추천했어요."
- **오류 대비**: 조회 실패 시 재시도, 마지막 예보 표시, 날씨 직접 입력(시연용)
- **룩북·프로필·다크 모드 저장**, 주간 코디 플랜, 기온별 옷차림 가이드, 쇼핑몰 검색 연결

## 구조
| 경로 | 내용 |
| --- | --- |
| `index.html` | 앱 화면 전체 (HTML·CSS·JavaScript, 외부 라이브러리 없음) |
| `android/` | 앱 화면을 담는 안드로이드 WebView 프로젝트 (Java) |
| `.github/workflows/build-apk.yml` | push할 때마다 APK를 빌드해 Releases에 올리는 자동화 |

## APK 받기
저장소의 **Releases → latest → WeatherStyleLab.apk**를 휴대폰에서 내려받아 설치합니다.
(처음 설치할 때 '출처를 알 수 없는 앱' 허용 필요)

## 수정하는 법
`index.html`을 고쳐 main에 올리면 3~5분 뒤 새 APK가 자동으로 만들어집니다.
같은 서명 키를 쓰므로 기존 앱 위에 바로 업데이트 설치할 수 있습니다.
